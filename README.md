## 🧩 Things I've Built: Multi-System AI Agents & Custom MCP Suite

### 1. Multi-System AI Agents for Better Workflow
To avoid single-model context saturation and failure modes in complex tasks, I engineered **multi-system AI agent workflows**. Specialized agents operate collaboratively within sandboxed local boundaries to deliver verified, high-throughput results:
- **Orchestrator & Planner**: Breaks user intent into task dependency graphs (DAGs) and delegates to domain sub-agents.
- **Code & Refactor Agent**: Inspects local repositories, implements features, and refactors components via sandboxed filesystem tools.
- **Shell & Diagnostics Agent**: Safely executes approved build scripts, test suites, and git operations with human-confirmation checks.
- **Error Triage & Log Agent**: Monitors local debug directories, parses stack traces, and suggests targeted patches without manual copy-pasting.
- **Research & Scraping Agent**: Leverages headless browser automation to pull real-time documentation and API specs directly into context.
- **UI Inspector Agent**: Captures automated dev-server screenshots to visually review CSS/layouts using multimodal vision models.

### 2. Custom Model Context Protocol (MCP) Tool Suite
I built a suite of **10 Model Context Protocol (MCP) servers** providing safe, standardized system capabilities:

| MCP Tool | What It Does | Why Build It |
| :--- | :--- | :--- |
| **Local File System MCP** | Gives the AI safe, sandboxed read and write access to a specific local folder or project directory. | Lets the model inspect, edit, or refactor code and notes directly on the machine without granting broad system access. |
| **SQLite / Local Database MCP** | Exposes local SQLite, Postgres, or MySQL databases to natural-language queries. | Lets you ask the AI to analyze tables, write queries, or summarize local data models on the fly. |
| **Personal Notes & Markdown MCP** | Scans local Obsidian, Notion export, or markdown vaults. | Turns personal second-brain notes into an instantly searchable, queryable knowledge base for the AI. |
| **Local Shell / Command Execution MCP** | Executes approved, safe shell commands or scripts locally (e.g., git status, tests, builds). | Allows the assistant to run diagnostics, compile code, or automate terminal tasks with your confirmation. |
| **Custom API / Internal Tool MCP** | Wraps private internal REST/GraphQL APIs and microservices. | Enables the AI to trigger internal microservices, fetch project records, or deploy builds securely. |
| **Browser Scraping & Research MCP** | Uses headless Playwright or a custom fetch/parsing script to scrape live web pages. | Pulls real-time documentation, articles, or pricing data directly into your chat context. |
| **Git Commit & Issue Tracker MCP** | Interacts with local git logs, branches, or self-hosted trackers like Linear/Jira. | Automatically drafts commit messages, summarizes recent diffs, or tracks open bugs from your workspace. |
| **Calendar & To-Do List MCP** | Connects to local calendars (iCal) or personal task files (like TODO.md or local SQLite lists). | Lets the AI check your schedule, block out deep-work time, or add actionable tasks. |
| **Log Analyzer & Error Triage MCP** | Monitors local log files or crash reports in a designated debug directory. | Paste-free debugging where the AI reads the stack trace straight from your log file and suggests a fix. |
| **Screenshot / UI Inspector MCP** | Takes automated screenshots of a running local dev server or UI component. | Lets multimodal AI visually inspect web app layouts or catch CSS/design bugs without manual uploading. |
